# Runtime Issue Analysis

본 문서는 개발·출시·전시·사용자 테스트 과정에서 실제로 재현한 런타임 이슈를 문제 해결과 향후 개선 방향으로 정리했습니다.

각 항목은 증상만 나열하지 않고 **영향도 → 재현 조건 → 관찰 결과 → 원인 → 수정 → 확인 결과 → 향후 개선 방향**의 순서로 구성했습니다.

> 재발 방지 항목은 현재 수정 내용에 더해 후속 리팩터링 또는 테스트 자동화 시 검토할 방향입니다.

---

# 필연과 우연

## Issue 1. 행동력 연속 클릭으로 인한 중복 차감

- **영향도:** High
- **재현 조건:** 조사 오브젝트 또는 퍼즐을 빠르게 연속 클릭
- **관찰 결과:** 행동력이 한 번에 여러 개 차감되고 날짜 진행 상태가 어긋남
- **확인한 원인:** 이벤트 처리 중 추가 입력 차단과 차감 전 상태 검증이 부족
- **수정:** 내부 행동력과 하트 UI를 함께 검사하고 처리 중 동일 상호작용 재실행 차단
- **확인 결과:** 한 번의 조사에 한 번만 차감되도록 확인
- **향후 개선 방향:** 행동력 변경을 단일 상태 모델과 이벤트로 관리하는 자동 경계값 테스트 검토

## Issue 2. 퍼즐 오브젝트가 비정상 DropZone에 배치되는 문제

- **영향도:** High
- **재현 조건:** DropZone 경계 또는 화면 밖 방향으로 드롭
- **관찰 결과:** UI 위치와 내부 배치 정보가 어긋나 정답 판정에 영향
- **확인한 원인:** 좌표 변환 이후 위치와 비즈 간 순서 제약을 함께 검사하지 않음
- **수정:** RectTransformUtility, 최근접 DropZone 탐색과 행별 제약 검사 추가
- **확인 결과:** 유효 위치 보정 또는 원래 위치 복귀와 내부 데이터 동기화 확인
- **향후 개선 방향:** 드롭 경계·화면 비율별 테스트 케이스 추가 검토

## Issue 3. 반복 클릭음으로 인해 핵심 효과음이 유실되는 문제

- **영향도:** Medium
- **재현 조건:** 빠른 반복 클릭 중 날짜 전환·이벤트 효과음 요청
- **관찰 결과:** 반복음이 AudioSource를 점유해 중요 효과음이 재생되지 않음
- **확인한 원인:** 모든 효과음이 같은 채널 자원을 경쟁
- **수정:** Low/High 우선순위, 예약 채널, Voice Stealing과 Debounce 적용
- **확인 결과:** 반복 클릭 중 핵심 이벤트 효과음 재생 확인
- **향후 개선 방향:** 채널별 실제 Priority 상태 추적과 디버그 뷰 검토

## Issue 4. 시계 퍼즐 비활성화 후 조작 상태가 남는 문제

- **영향도:** Medium
- **재현 조건:** 시계 퍼즐 조작 중 귀가 이벤트 또는 오브젝트 비활성화
- **관찰 결과:** 효과음 지속 또는 재진입 후 조작 불가
- **확인한 원인:** 드래그 상태와 스냅 Coroutine이 비활성화 시 정리되지 않음
- **수정:** OnDisable에서 Coroutine 중단, dragging/isSnapping/루프 효과음 초기화
- **확인 결과:** 귀가·씬 전환 이후 재진입 조작 확인
- **향후 개선 방향:** OnDisable/OnDestroy 정리 규칙을 공통 인터페이스로 통일 검토

## Issue 5. 선택지 이벤트 이후 후속 Result가 실행되지 않는 문제

- **영향도:** High
- **재현 조건:** 선택지에서 다음 Event를 호출
- **관찰 결과:** 기존 대화창이 남고 후속 대사·Result가 실행되지 않음
- **확인한 원인:** 기존 Dialogue 상태 종료 전 다음 Event 호출
- **수정:** EndDialogue 후 다음 이벤트를 실행하도록 순서 변경
- **확인 결과:** 선택지 이후 후속 대사와 이벤트 연결 확인
- **향후 개선 방향:** 상태 전환 API를 통해 Dialogue 종료와 Event 호출 순서 강제 검토

## Issue 6. 저장 복원 시 Lock UI가 표시되지 않는 문제

- **영향도:** Medium
- **재현 조건:** Lock UI가 열린 상태로 저장 후 이어하기
- **관찰 결과:** 잠금 UI와 Blur·입력 차단이 복원되지 않음
- **확인한 원인:** CanvasGroup이 자식에 있어 복원 경로에서 대상을 찾지 못함
- **수정:** GetComponentInChildren<CanvasGroup>(true)로 비활성 자식 탐색
- **확인 결과:** 일반 호출과 저장 복원 경로에서 동일 표시 확인
- **향후 개선 방향:** Prefab 구조 검증과 복원 대상 인터페이스 도입 검토

## Issue 7. Room2 이어하기 시 ActionPoint가 잘못 복원되는 문제

- **영향도:** High
- **재현 조건:** Day2 이후 저장 후 이어하기
- **관찰 결과:** Day1 기준 행동력과 하트 UI로 복원
- **확인한 원인:** 현재 날짜가 아닌 배열 0번 인덱스 사용
- **수정:** 저장된 NowDayNum으로 날짜 인덱스를 계산해 복원
- **확인 결과:** 내부 ActionPoint와 하트 UI 일치 확인
- **향후 개선 방향:** 날짜 경계값별 Save/Load 회귀 테스트 추가 검토

## Issue 8. 저장된 귀가 이벤트 플래그가 오작동하는 문제

- **영향도:** High
- **재현 조건:** 행동력 0 상태 저장 후 이어하기와 일반 조사
- **관찰 결과:** 의도하지 않은 귀가 이벤트 실행
- **확인한 원인:** 세션용 임시 플래그가 저장 데이터에 포함
- **수정:** 플래그를 런타임 변수로 분리하고 시작 시 초기화
- **확인 결과:** 현재 세션에서 행동력이 0이 된 경우에만 실행 확인
- **향후 개선 방향:** 영속 상태와 런타임 임시 상태의 데이터 모델 분리 규칙 검토

## Issue 9. Save/Load 이후 오브젝트 이미지가 갱신되지 않는 문제

- **영향도:** Medium
- **재현 조건:** 상태 기반 오브젝트 변경 후 저장·이어하기
- **관찰 결과:** 이미지와 내부 진행 상태 불일치
- **확인한 원인:** 상태 변수만 복원하고 Side·Zoom View 갱신 누락
- **수정:** OnEnable에서 저장 상태를 읽고 관련 이미지를 함께 갱신
- **확인 결과:** 복원 후 화면과 내부 상태 일치 확인
- **향후 개선 방향:** 상태 변경 이벤트 기반 View 갱신으로 통합 검토

# 네 발자국

## Issue 10. 대화 스킵 시 마지막 컷씬과 자동 진행이 실행되지 않는 문제

- **영향도:** High
- **재현 조건:** Skip 버튼으로 마지막 대사까지 이동
- **관찰 결과:** 마지막 컷씬, AUTO_DELAYED, FADE_OUT 미실행
- **확인한 원인:** Coroutine 중단으로 공통 마무리 경로 우회
- **수정:** 스킵 상태를 추가하고 마지막 라인 후 공통 후처리 실행
- **확인 결과:** 스킵 여부와 무관하게 컷씬·자동 진행·종료 확인
- **향후 개선 방향:** 정상/스킵 경로가 동일한 종료 함수를 사용하도록 유지

## Issue 11. MemoryPuzzleStates 직렬화 오류로 Save/Load가 실패하는 문제

- **영향도:** Critical
- **재현 조건:** MemoryPuzzleStates 포함 저장 데이터 불러오기
- **관찰 결과:** 역직렬화 오류와 NullReferenceException
- **확인한 원인:** Dictionary<int,bool>이 JSON이 아닌 타입명 문자열로 저장
- **수정:** 전용 타입 JSON 직렬화와 손상 데이터 fallback 추가
- **확인 결과:** 복합 타입 정상 복원과 일부 오류의 전체 실패 차단 확인
- **향후 개선 방향:** 타입별 저장 단위 테스트와 saveVersion Migration 도입 검토

## Issue 12. 회상 선택으로 책임점수가 중복 누적되는 문제

- **영향도:** High
- **재현 조건:** 저장 후 동일 회상 흐름 재실행
- **관찰 결과:** ResponsibilityScore가 반복 증가 가능
- **확인한 원인:** 선택 Event마다 점수를 직접 증가
- **수정:** MemoryPuzzleStates를 단일 진실원천으로 사용해 true 개수로 재계산
- **확인 결과:** 회상 상태·점수·엔딩 분기 일치 확인
- **향후 개선 방향:** 파생 값은 원본 상태에서 계산한다는 규칙 문서화

## Issue 13. 퍼즐 가방에서 플레이어 이름이 잘못 표시되는 문제

- **영향도:** Low
- **재현 조건:** 이름 설정 후 회상 텍스트 확인
- **관찰 결과:** 초기 임시 이름이 표시
- **확인한 원인:** Awake에서 이름 확정 전 플레이스홀더를 치환해 저장
- **수정:** CSV 원문을 유지하고 UI 갱신 시 현재 이름으로 치환
- **확인 결과:** 이름 설정과 Save/Load 이후 최신 이름 반영 확인
- **향후 개선 방향:** 동적 데이터 치환 시점을 View 렌더링 단계로 통일

## Issue 14. UnityEvent의 씬 경계 참조가 불안정한 문제

- **영향도:** High
- **재현 조건:** 튜토리얼 UnityEvent에서 DontDestroyOnLoad 서비스 호출
- **관찰 결과:** 씬 전환 이후 Inspector 참조가 깨질 수 있음
- **확인한 원인:** UnityEvent 참조가 씬 객체 기준으로 직렬화
- **수정:** ScriptableObject ServiceAction Command가 실행 시 서비스를 탐색해 호출
- **확인 결과:** 씬 전환과 무관한 서비스 호출 확장 확인
- **향후 개선 방향:** 서비스 식별과 실패 로그를 포함한 공통 Command Registry 검토

## Issue 15. Stage3 마지막 NPC 발걸음이 재생되지 않는 문제

- **영향도:** Medium
- **재현 조건:** 추격 구간 마지막 NPC 이동
- **관찰 결과:** 발걸음 효과음 미재생
- **확인한 원인:** 발걸음과 환경음이 같은 AudioSource를 사용해 Stop·Volume이 간섭
- **수정:** NPC 발걸음 전용 AudioSource로 재생 경로 분리
- **확인 결과:** 환경음 상태와 무관한 발걸음 재생 확인
- **향후 개선 방향:** 오디오 용도별 Source 책임을 명시하고 동시 재생 테스트 유지

## Issue 16. BGM 전환 중 오디오 메모리가 부족해지는 문제

- **영향도:** Critical
- **재현 조건:** 반복 씬 전환 또는 BGM 크로스페이드
- **관찰 결과:** FMOD 오디오 메모리 할당 실패
- **확인한 원인:** 이전 Fade Coroutine, AudioClip과 루프 사운드 참조가 잔존
- **수정:** BGM Source 수 제한, Coroutine 중단, Stop과 clip=null 정리
- **확인 결과:** 반복 전환 후 사용하지 않는 오디오 자원 누적 방지 확인
- **향후 개선 방향:** 씬 전환 전 오디오 정리 체크리스트와 프로파일링 기준 추가 검토

# 공통 문제 해결 방식

1. 사용자 입력과 저장 상태 등 재현 조건을 구체화했습니다.
2. 정상 처리 순서와 실제 실행 결과를 비교했습니다.
3. 단일 증상보다 상태값, Coroutine, Scene 수명주기와 자원 소유 관계를 확인했습니다.
4. 수정 후 관련 상태·UI·연출과 Save/Load 경로를 함께 확인했습니다.
5. 구조적 원인을 발견한 경우 영속/런타임 상태 분리, Command, 전용 Source와 같은 예방 구조를 검토했습니다.
